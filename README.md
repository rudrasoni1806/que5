# Rhythm & Radiance 2026 – College Fest Page

A simple, responsive college fest webpage built with HTML and an external CSS stylesheet.

## Files
- `index.html` – semantic college fest page with Events, Guests and Contact articles.
- `style.css` – external stylesheet with a five-colour palette, element, class, ID, group and descendant selectors.

## Styling requirements covered
- All styling is in `style.css`; there are no inline style attributes or embedded style tags.
- Five-colour palette: navy (`#182848`), coral (`rgb(255, 107, 107)`), gold (`#F4C95D`), cream (`#FFF8E7`) and teal (`teal`).
- Body font stack uses installed system fonts: Arial, Helvetica, sans-serif.
- Group selector: `h1, h2`.
- Descendant selector: `footer p`.

## Run locally
Keep `index.html` and `style.css` in the same folder, then open `index.html` in a browser.

## Publish on GitHub
Create a **public** repository named `college-fest-page`. From this folder, run:

```bash
git init
git add .
git commit -m "Add college fest page and external stylesheet"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/college-fest-page.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
